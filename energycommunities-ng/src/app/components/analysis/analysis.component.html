Energy Community Analysis

Profile analysis Take a list of members, each with one or more energy profiles. This analysis picks the best profile for each member to create an ideal energy community, where everyone follows their optimal profile.
Optimal Community Formation Build a new energy-sharing group from a list of available members. Choose which members can join and the community size. The system checks all combinations to find the best setup that maximizes energy sharing.
Community Adjustment Optimization Improve an existing energy community. Mark members who can be added or removed. The system tests all options to find the most efficient configuration, showing if adding or removing members improves energy sharing and community balance.
Optimal Battery Assignment For each energy community, given a set of candidate batteries and a predefined budget, our app runs an optimization algorithm that selects which producers should be equipped with batteries and dynamically schedules charge/discharge operations.
