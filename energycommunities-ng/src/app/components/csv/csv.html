How to Fill the CSV

The CSV file must follow this structure: 

id,full_name,email,category,t0,t1,t2,t3,t4,t5,t6,t7,t8,t9,t10,t11,t12,t13,t14,t15,t16,t17,t18,t19,t20,t21,t22,t23

Each row represents a consumption or production profile for a user. Each user can have multiple profiles. The category field can be either CONSUMER or PRODUCER. The columns t0–t23 represent the energy consumption or production (in kW) for each hour of the day. Each user must have a unique identifier in the email field.
